- **Die Bilder zeigen keine von Gartenkunst Galla ausgeführten Projekte.** Sie sind auf der Website
  als „Bildwelt zur Designillustration – keine dokumentierten Galla-Referenzprojekte“ gekennzeichnet.
- Es gibt **kein Portrait von Heinrich Galla** – stattdessen eine typografische Darstellung
  (kein KI-generiertes oder fremdes Bild).
- Die Bilder wurden für das Web in WebP-Varianten (640/1080/1600/2400 px Breite) umgerechnet
  und liegen unter `public/images/`. Auf der Website wird per CSS eine dezente, einheitliche
  Farbanmutung (leicht reduzierte Sättigung) angewendet.

## Offener Punkt vor einem produktiven Einsatz

Die Fotografinnen und Fotografen konnten in der Entwicklungsumgebung nicht automatisiert
ermittelt werden (die Unsplash-Fotoseiten waren nicht abrufbar; das Bild-CDN liefert keine
Urheberangaben). Eine Namensnennung ist nach der Unsplash-Lizenz nicht verpflichtend, wird aber
empfohlen. **Vor einer Veröffentlichung über die Demo hinaus** sollten die Urheber über die
Original-URLs bzw. die Unsplash-Suche ergänzt werden – oder die Bilder werden ohnehin durch
echte Projektfotos von Gartenkunst Galla ersetzt (empfohlen).
